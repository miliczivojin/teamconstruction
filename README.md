# TEAM CONSTRUCTION 018 - Zvanični Veb-Sajt

Zvanična veb-prezentacija za građevinsku kompaniju **TEAM CONSTRUCTION 018 d.o.o.** (teamconstruction.rs), razvijena kao moderna, brza i responzivna jednostrana aplikacija.

## 🚀 Tehnologije

Projekat je izgrađen korišćenjem savremenih alata za frontend razvoj:

* **React** - Biblioteka za izgradnju korisničkog interfejsa kroz komponente.
* **Vite** - Brz alat za build-ovanje i razvojno okruženje.
* **JavaScript (ES6+)** - Glavni programski jezik projekta.
* **CSS3** - Za stilizaciju, responzivni dizajn i vizuelni identitet sajta.
